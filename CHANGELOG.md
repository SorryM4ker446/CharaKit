- Local source snapshots, candidate versions, technical checks, full-image and whole-face previews, review/selection, and byte-preserving PNG ZIP exports.
- User-language responses, prompts, quality explanations, review notes, and optional localized preview labels.
- English and Simplified Chinese documentation with README language navigation, local/Git marketplace installation, synthetic-fixture tests, GitHub CI, and plugin packaging.
