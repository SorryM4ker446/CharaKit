# CharaKit releases

## 0.2.0-beta.1 — 2026-10-23

First public beta. The bundled [release notes](plugins/charakit/RELEASE_NOTES.md) describe installation, supported workflows, validation scope and known limitations.

- Consolidate Expressions, four Outfits modes and eight static dialogue poses with scoped references, bounded redraws, retained versions, human revisions and original PNG/ZIP delivery.
- Allow different source/output resolutions with localized size warnings. Keep acceptance, selected-version metadata and delivery reports consistent while preserving historical feedback and original files.
- Add repeatable workflow/browser QA, independent export/warning audits and evidence-bound manual mouth continuity acceptance. Keep page templates in Python and reject standalone HTML files in plugin packages.
- Add MIT licensing, an installable marketplace ZIP, clean Python dependency verification and isolated Codex CLI installation checks.
- Retain scoped real-call evidence: 11 user-accepted deliveries on one source, including two poses, and 209 final export audit checks. Broader character/style quality, all real pose presets and game-engine continuity remain unverified.

Earlier development milestones are retained in the [roadmap](plugins/charakit/ROADMAP.md).
